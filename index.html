Workflow Automation · n8n

Multi-Segment CRM Follow-Up Automation

This is an end-to-end lead follow-up system I built in n8n to replace manual outreach and manual CRM updates. It picks up rows from a Google Sheet, splits leads into three tracks, and runs each one through its own outreach + follow-up sequence without me touching it.

How the workflow runs

  1. Trigger & fetch: The workflow starts manually or on schedule, pulls new rows from a Google Sheet, then loops over every lead in the batch.
  2. Smart routing: A Switch node reads each lead's type and routes it down one of three parallel branches — B2B, Agency, or Others — so each segment gets messaging built for it.
  3. First touch: Each branch sends an initial personalized message (email), then immediately updates that lead's row in the sheet to log the outreach.
  4. Reply detection: A filter step checks whether the lead replied. Leads that responded exit the sequence; the rest continue automatically.
  5. Delayed follow-ups: For leads that stayed silent, a Wait node pauses for 2–3 days, then sends a follow-up message and updates the sheet again — this repeats up to 3 times per lead.
  6. CRM sync: Every send, reply, and delay is written back to the Google Sheet in real time, so the CRM always reflects the true status of every lead without manual data entry.

Why it matters

Before this system, follow-ups were tracked manually, which meant leads slipped through the cracks. Automating the routing, timing, and CRM updates means every lead gets a consistent, timely follow-up sequence and the sheet never falls out of sync — freeing up hours every week that used to go into manual outreach tracking.

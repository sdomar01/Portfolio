Flow Remote Ops Website

A website for Flow Remote Ops, a remote staffing and operations company that serves founders and growing businesses in the US, UK, and Australia. It explains the services, speaks to both employers and job seekers, and collects inquiries and applications through web forms.

About the site

Who it is for and what it offers

The homepage opens with the promise "We Run the Back End. You Build the Business." and a button to book a free Ops Audit. It then splits into two tracks: one for businesses that want reliable remote capacity, and one for people who want a remote operations career.

  • Executive and admin support
  • Finance and bookkeeping
  • Creative and content
  • Systems and automation

Hosting and deployment

The site collects information through web forms. The website contact form sends each submission to Google Sheets through Google Apps Script.

Web forms

Four ways to get in touch

The site offers these forms. The contact form is connected to Google Sheets through Google Apps Script.

For businesses that want to talk about a remote team or book an Ops Audit.

For remote job seekers who want to apply to join the team.

Candidate Inquiry

For talent who have questions before applying.

Candidate Referral

For people who want to refer someone they know.

How it works

From visitor to submission

  1. Python FlaskServes the website pages, deployed on Railway
  2. Web formVisitor fills in the HTML contact form
  3. JavaScriptHandles the form on the page
  4. Google Apps ScriptReceives the submission
  5. Google SheetsStores the lead information

Skills shown

What this project demonstrates

  • Web development. A multi-section business website built with Python Flask, HTML, CSS, and JavaScript, with responsive layouts and interactive features.
  • Form handling. A contact form connected to Google Sheets through Google Apps Script.
  • Deployment and version control. Source code managed with Git and GitHub, and the site deployed and maintained on Railway.
  • Lightweight automation. Using Google Apps Script to move website leads into Google Sheets without a heavier backend.
